# Agent Skills

This repository expects contributors to apply the following capabilities deliberately and with evidence.

| Skill | Use |
| --- | --- |
| Repository orientation | Read architecture, workflow, issue, progress, and affected code before acting. |
| Python engineering | Write clear, typed where practical, testable pipeline code; avoid hidden state. |
| SQL Server extraction | Use parameterized, read-only queries and validate source schema and period boundaries. |
| PostgreSQL persistence | Use migrations, transactions, constraints, indexes, and least-privilege access. |
| ETL/data quality | Validate freshness, completeness, uniqueness, nulls, reconciliation counts, and schema drift. |
| ML/association mining | Track data window, basket definition, parameters, metrics, and comparison baseline. |
| Testing | Use unit, integration, regression, and data-quality tests appropriate to the change. |
| Security | Protect secrets, sanitize logs, minimize access, and review dependencies. |
| Observability | Emit actionable run status, timing, record counts, quality results, and failures. |
| Documentation | Maintain architecture, runbooks, environment examples, progress records, and issue evidence. |

Skills do not grant production authority. Follow the workflow and escalate when permissions or risk require a human decision.
